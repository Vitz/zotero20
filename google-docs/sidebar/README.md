# Panel importu ORCID/DOI

Base URL: `https://zotero.keyweb.pl/api/v1`

## Script Properties

| Klucz | Wartość |
|-------|---------|
| `ZOTERO20_API_KEY` | klucz z `server/.env` (wymagany) |

## Użycie

Rozszerzenia → Zotero20 → Otwórz panel importu.

Cytowania: menu **Zotero** w Docs (fork Connector z tym samym API key).
