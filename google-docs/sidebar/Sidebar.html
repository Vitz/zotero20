API Zotero

Importuj źródła do kolekcji na serwerze, wstawiaj śledzone cytowania i buduj bibliografię z tego, co faktycznie zacytowane.

Kolekcja tego dokumentu

Numer DOI jednej publikacji (np. 10.1038/… lub polski 10.14313/PAR_255/81). Import wielu prac autora — zakładka „Autor (ORCID)”.

Zaawansowane: nadpisz badaniem z studies.yaml
Kolekcja tego dokumentu

Profil ORCID autora (format 0000-0002-1825-0097), nie DOI artykułu. Pojedynczy artykuł — zakładka „Pojedynczy DOI”.

Zaawansowane (import ORCID)

Ile prac pobrać z profilu ORCID przy jednym imporcie (1–200). Nie dotyczy importu pojedynczego DOI.

Nadpisz kolekcję dokumentu badaniem z studies.yaml.

Kolekcja tego dokumentu
Uzupełnij z tekstu (Gemini)

Wklej abstrakt, opis albo cytowanie. Model wypełni pola poniżej — sprawdź je przed utworzeniem. Przy kluczu w Ustawieniach zapytanie idzie bezpośrednio do Google Gemini (nie przez VPS / Cloudflare). Utworzenie pozycji nadal przez serwer.

DeepL — tłumaczenie zaznaczenia

Zaznacz tekst w dokumencie, ustaw łańcuch języków (A → B → C…), potem Tłumacz zaznaczony tekst. Każdy krok bierze wynik poprzedniego. Klucz zostaje w Script Properties (nie w repo). Wywołanie idzie bezpośrednio do DeepL.

Łańcuch tłumaczeń

Kolejność = kolejność wywołań DeepL. Przykład: EN → PL → DE → EN (przełożenie przez pośrednie języki i powrót).

Opcje DeepL

DeepL Write — poprawa tekstu

Poprawia / przeredagowuje zaznaczenie w tym samym języku (/v2/write/rephrase lub /correct). Wymaga API Pro. DeepL Write nie wspiera PL (en-US, de, fr…). Domyślnie wstawia jako sugerowaną zmianę w Docs — zaakceptuj lub odrzuć w dokumencie.
